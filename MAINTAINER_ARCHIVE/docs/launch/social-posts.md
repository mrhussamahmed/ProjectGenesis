## Reddit Draft

Title: I built a Markdown-first scaffold for AI-assisted software delivery

I have been working on ProjectGenesis, a repository scaffold for using AI coding
agents without letting chat history become the source of truth.

It includes shared agent rules, role files, intake structure, requirements and
assumption registers, specs, backlog, ADRs, validation plans, reviews, and
handoffs.

The main workflow starts with rough input and asks an agent to run:

```text
Start requirement breakdown.
```

The output should separate confirmed facts, inferences, assumptions, open
questions, risks, backlog candidates, and validation needs before implementation
starts.

It is intentionally plain Markdown and shell. It does not pick a stack or try
to generate a full app.

Feedback on setup friction, missing examples, and governance weight would be
useful.
