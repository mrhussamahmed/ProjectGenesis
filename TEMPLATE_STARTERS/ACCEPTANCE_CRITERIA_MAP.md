# Acceptance Criteria Map

Map acceptance criteria to automated and manual tests. Copy this starter to
`TESTS/ACCEPTANCE_CRITERIA_MAP.md` in a new project.

| Spec | Acceptance Criteria | Test Type | Test File Or Checklist | Status | Notes |
|------|---------------------|-----------|------------------------|--------|-------|
| none | none | none | none | none | No acceptance criteria mapped yet. |

## Rules

- Add one row per acceptance criterion when its spec is approved or active.
- Every `passed` row must name a real test artifact or checklist run.
- Statuses: `pending`, `passed`, `failed`, `blocked`, `superseded`.
- Keep one row per criterion; update in place rather than appending history.
